# Instalação

Para instalar o SGE, verificar se o .env está devidamente configurado, caso sim siga os passo abaixo:

1. Clone o repositório:
    ```bash 
    git clone https://github.com/NunesDevelloper/TCC_SENAI PROJETO_FINAL
    ```
2. Entra na pasta SGE:
    ```bash 
    cd PROJETO_FINAL
    ```
3. Rode o Docker:
    ```bash 
    docker compose up --build
    ```

Apos isso basta acessar http://localhost:8000/docs .
